# [feat] 피드백 근거 개선 및 GPT 코칭 검토 흐름 추가

## 작업 내용

### 1. 분석 근거에 맞춘 피드백

- 신뢰도가 충분한 관절·구간만 개선 후보로 사용
- 잘한 구간과 먼저 확인할 동작을 구분하고 점수 산출 이유 설명
- 구간 평균을 순간의 목표 자세로 안내하거나, 비교 자료 없이 이전 기록이 없다고 단정하는 문구 검사
- GPT 입력의 중복 정보를 줄이면서 측정값·신뢰도·제외 사유 유지

### 2. GPT 검토 상태와 규칙 기반 안내

- 생성 성공과 사용자 표시 승인을 분리
- 검토 필요·정책 위반·호출 실패 시 규칙 기반 안내 표시
- 승인한 문구와 분석 근거가 일치할 때만 GPT 코칭 표시
- 이전 스윙 비교 조회에서는 새 GPT 호출을 하지 않도록 변경

### 3. 피드백 화면 정리

- 총점·요약을 먼저 표시하고 자세·속도 구성점수와 상세 근거는 펼쳐서 확인
- GPT 코칭과 규칙 기반 문구의 출처 구분
- 기존 관절·구간 UI, 스윙 추이, 원본 삭제, 3D 기능 유지

## 검증

- Flutter analyze 및 Web build 통과
- Flutter 전체 310개 및 웹 전용 Blob 3개 통과
- 백엔드 265개 통과, OpenCV 환경 오류 3개는 기존 영상 환경에서 보완 통과
- 격리 Chrome 앱의 로그인·피드백·추이·삭제·3D 회귀 53항목 통과
- 기존 6개 리포트의 점수·피처와 저장된 실제 GPT A/B 결과 보존

최종 통과 수와 환경별 제외 사유는 [최종 검수 보고서](https://github.com/projectbaseballswing/standardswingmodel/blob/feat/feedback-coaching-integration/docs/feedback-coaching-final-review.md)에 기록합니다.

웹 전용 검증은 Windows 테스트 서버의 CanvasKit 404를 동일 SDK 파일 제공으로 우회했습니다. GitHub CI 결과는 PR의 Checks에서 별도로 확인합니다.

## 주의사항

- DB migration은 없습니다. 기존 점수 모델과 실제 코칭 원문은 변경하지 않았습니다.
- 실제 GPT B는 검토 대기 상태입니다. 승인 화면 검증에 사용한 합성 예시는 운영 데이터가 아닙니다.
- 이번 검증에는 추가 OpenAI 호출이나 운영 Supabase 변경이 없습니다.
- 초기 배포는 규칙 기반 안내로 운영하고, GPT 생성 활성화 전 관리자 검토·저장 권한을 준비해야 합니다. 서버에 OpenAI 키가 설정돼 있으면 표시 승인과 별개로 생성 비용이 발생할 수 있습니다.
- 입력 크기 감소는 바이트 기준이며 새 프롬프트의 생성 품질·비용 개선은 아직 검증하지 않았습니다.
