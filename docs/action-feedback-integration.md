# 행동 중심 피드백 GitHub 반영

2026-11-23. 기준 main: `8bfff2b` (PR #91 병합).

## 변경 내용

종합 피드백을 분석 결과 → 영상 확인 방법 → 조건부 연습으로 정리했다. 골반선 기울기, 골반 기준 앞발 위치, 어깨 기준 손 높이, 앞·뒤 팔꿈치에 피처별 안내를 제공한다. 측정 한계는 펼쳐 보는 상세 설명으로 분리했다.

- 골반 기울기를 줄이거나 수평으로 맞추도록 지시하지 않는다. 원본에서 몸의 흔들림과 보정 발 디딤 등 실제 균형 문제가 확인될 때만 작은 동작 재현을 제안한다.
- 팔꿈치의 큰 각도 차이와 medium 신뢰도는 교정 타당성의 증거가 아니다. 원본에서 실제 팔 모양을 확인하며 수치 차이만큼 꺾도록 지시하지 않는다.
- 기존 영상 확인이 우선이며 추가 촬영은 선택이다. 기준 선수 영상은 제공되지 않는다. 유효한 비교 데이터가 있을 때 관절 그래프로 수치를 대조하도록 안내한다.
- 내 측정값·기준 평균·편차 영역의 그래프 범례를 추가했다. 좌표·시간축·그래프 계산은 변경하지 않았다.
- low/결측/추적 품질에 따른 보류를 유지한다. 낮은 평균 추적 지표를 가림이나 프레임별 오검출의 확정 증거로 바꾸지 않는다.
- GPT 승인·차단·폴백 정책과 로그인·추이·원본 삭제·3D 코드는 변경하지 않았다.

## PR #91과의 관계

기존 검수 기준 `8c11101` 이후 PR #91의 4개 파일을 확인했다. 이 작업은 해당 파일을 수정하지 않는다.

| 구간 | 최신 main의 가중치 |
|---|---:|
| 스윙 | 1.0 |
| 트랜지션 | 0.6 |
| 스트라이드 | 0.3 |

종합 자세 거리, 부위 점수, 점수 영향도에 적용된 가중 계산을 유지한다. 자세 70%·손 속도 30% 합산과 기준 모델 파일도 유지한다. 기준 모델 재산출 여부 등 PR #91 자체의 한계는 [구간 가중치 문서](scoring-phase-weights.md)를 따른다.

먼저 확인할 후보는 신뢰도 조건을 통과한 구간별 `|z|` 크기로 고르는 기존 순서다. 가중된 점수 영향도 순서·종합점수 감점량·전문적인 교정 우선순위가 아니다. 이 구분을 펼침 설명과 회귀 테스트에 명시했다. 과거 리포트는 재계산하지 않으며, 구간 가중치 도입 전후 차이를 이번 UI 기능의 회귀로 취급하지 않는다.

## 검증

원본 리포트·좌표·캡처·실행 로그·브라우저 프로필은 로컬에만 보존한다.

1. 동일한 저장 리포트 6개를 최종 검수본과 반영 브랜치의 실제 Flutter 매핑에 적용해 점수·측정값·후보 순서·적격 조건을 비교한다.
2. 이 비교와 별도로 최신 main을 깨끗하게 추출하고, 동일한 저장 30/60FPS 좌표를 두 코드에서 재계산한다. 양쪽 handedness 매핑과 명시적으로 손목을 결측 처리한 변형을 포함한 5조건의 전체 리포트·피처·기준 모델 해시를 대조한다. 새 영상 추론이나 정확도 평가는 아니다.
3. Flutter 전체 테스트와 백엔드 회귀 테스트에서 인증·소유권·GPT 미승인 차단·기존 추이·영상 삭제·3D를 함께 확인한다. 백엔드는 임시 SQLite와 테스트 Storage를 사용한다.
4. Chrome은 저장 리포트와 별도 표시 fixture를 사용하는 실제 종합·관절·구간 위젯을 검사한다. 실제 로그인·업로드·원본 영상 재생 및 Android 검증은 이번 범위에 포함하지 않는다.

### 자동 검사 결과

- Flutter analyze: 문제 없음.
- Flutter 전체 테스트: **347개 통과, 6개 제외**. 3개는 VM에서 실행하지 않는 웹 Blob 테스트이며 기존 CI의 Chrome 전용 단계에서 실행한다. 나머지 3개는 서비스에서 의도적으로 숨긴 기존 3D 모드 전환 테스트다.
- 백엔드: **308개 통과, 16개 제외**. 최초 실행은 280개 통과·15개 제외·29개 준비 오류였다. 오류는 기존 Windows `pytest-of-DO` 임시 폴더의 접근 거부였다. 접근 권한을 바꾸거나 테스트를 약화하지 않고 새 worktree의 전용 `--basetemp`로 오류 29개만 재실행해 28개 통과·1개 제외를 확인했다.
- 백엔드 제외 사유: 비공개 스켈레톤/이벤트 자료를 요구하는 14개, 의도적으로 비활성화한 실제 Supabase 1개, Windows 심볼릭 링크 생성 권한이 없는 1개다. Linux CI에서는 마지막 항목도 실행 가능한 조건이다. 통과하지 않은 항목을 통과로 계산하지 않았다.
- 저장 6리포트 Flutter 재생 검사: 1개 통과, 비교 항목 **228행**의 점수·측정값·후보 순서·연습 조건 동일. 이번 추가 변경은 우선 확인 후보의 의미를 설명하는 상세 문장뿐이다.
- 최신 main/작업 브랜치의 같은 입력 재계산: **5조건 전체 리포트·피처 일치**. 저장 좌표는 30FPS 56프레임과 59.94FPS 114프레임이며, 손목 결측 변형은 명시적인 검증 입력이다. 양쪽 handedness 설정 검사는 실제 좌타·우타 정확도 검증이 아니다.
- 서비스 Web build: 성공. 추가 패키지·lockfile·Flutter SDK 변경 없이 설치된 캐시를 사용했다.
- Chrome: 종합→관절→구간 이동, 그래프 범례, 측정 한계, 조건부 연습, 큰 각도 차이의 원본 확인, 근거 부족·저신뢰의 연습 보류 등 **12개 검사 통과**. 브라우저 Runtime 오류와 실제 API·OpenAI·Supabase 요청은 0건이다. 최초 Chrome은 제한된 실행 환경의 Windows 내부 통신 권한 오류로 종료되어, 정상 권한의 전용 로컬 프로필에서 같은 검수를 다시 수행했다. 보안 옵션이나 앱 코드를 완화하지 않았다.
- GPT 미승인 응답 차단, 승인된 합성 예시와 규칙 기반 문구 구분, 점수 영향도, 로그인·추이·영상 삭제·3D 회귀 테스트가 포함된다. 실제 GPT 생성 또는 운영 Supabase E2E 결과가 아니다.

## 적용 범위와 남은 검증

DB migration·추가 패키지·서버 설정 변경이 필요하지 않은 Flutter 표시 변경이다. 모델 0.2·원본 분석·GPT 승인 정책은 유지하며 OpenAI 호출과 운영 Supabase 접근은 하지 않는다. 사용자에게 제안하는 연습의 효과나 실제 교정 필요성을 검증한 것은 아니다. 조건을 확인하기 어려운 영상에서는 연습을 보류한다.

원본 `swing-feedback-actions` 및 최종 검수 `swing-feedback-actions-review`의 HEAD·Git 상태·변경 파일 해시를 기록해 보존을 검사한다. 신규 반영 공간은 `swing-feedback-actions-publish`, 브랜치는 `feat/action-feedback-integration`이다.
