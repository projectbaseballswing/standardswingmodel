## 범위

- repository/model/종합 화면의 3개 충돌에서 양쪽 필드와 위젯을 유지했다.
- 부위별 `score_contributions`와 관절별 `contribution` 계산·응답 값을 보존한다. 모델 0.2 계산 코드는 수정하지 않았다.
- 영향도는 표시 범위의 표준화 차이 제곱합 비중이다. 종합 화면은 저신뢰도 포함하고 관절 화면은 같은 부위의 저신뢰 피처를 제외하므로 분모가 다르다. 종합점수 감점량·원인·교정 우선순위로 변환하지 않는다.
- GPT 입력에 이 구분과 실제 값을 보존하며 잘못된 인과/감점 설명은 검토 신호로 다룬다. 자동 의미 검증은 사람 검토를 대신하지 않는다.
- 자연어 템플릿의 전면 개선과 저신뢰 부위의 회색·중립 UI는 후속 PR의 범위다.

## 자동 유료 생성과 공개의 분리

`OPENAI_COACHING_ENABLED=0`이 기본값이다. 환경 변수를 생략하거나 다른 값으로 설정한 경우에도 비활성화된다. **키만 설정해서는 업로드 작업의 GPT 생성이 시작되지 않는다.** 비활성 상태에는 규칙 기반 피드백을 사용한다.

유료 생성에 대한 별도 승인과 검토 저장 환경을 준비한 뒤에만 `OPENAI_COACHING_ENABLED=1`과 키를 함께 설정한다. `OPENAI_COACHING_SCOPE`는 생성 범위이지 활성화 설정이 아니다. 생성이 활성화돼도 미승인 후보는 비공개이며 자동 승인하지 않는다. 이미 승인된 저장 코칭의 조회는 생성 설정과 별개로 기존 검토·소유권 정책을 적용한다.

이 설정은 FastAPI 작업 큐에 적용한다. 연구용 Python 함수에 키를 직접 전달해 호출하는 것은 별도의 명시적 실행이다. 이번 검증에서는 어떤 실제 OpenAI 호출도 하지 않는다. 운영 Supabase/기존 기록/환경 변수는 변경하지 않는다.
