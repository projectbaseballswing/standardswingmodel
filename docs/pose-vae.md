# VAE 개선 자세

사용자 스윙을 '프로다운' 스윙으로 옮긴 자세를 만든다. 사용자 체형과 프로에게도 흔한 스타일은 그대로 두고,
프로들이 하지 않는 움직임이 있는 순간만 고친다. **점수에는 쓰지 않는다** (보여주기용).

- 코드: `feedback/pose_vae.py` (서버, NumPy), `scripts/train_pose_vae.py` (학습, PyTorch)
- 모델: `feedback/pose_vae.npz`. 없으면 API 의 `improved` / `improvement` 가 null 이고 나머지 응답은 그대로다.
- API: `GET /api/analyses/{id}/reference-motion` 의 `phases[].improved`, `improvement` (docs/reference-motion-api.md)

## 기준 동작과의 차이

| | 기준 동작 (`reference`) | 개선 자세 (`improved`) |
|---|---|---|
| 정답 | 프로 800명 뼈 방향을 합친 대표 자세 하나 | 사용자 스윙에서 가장 가까운 프로다운 스윙 |
| 사용자마다 | 모두 같음 | 사람마다 다름 |
| 체형 | 표준 체형 | 사용자 뼈 길이 |
| 만드는 법 | 계산 (뼈 방향 최빈값) | VAE (학습) |

## 만드는 법

1. 입력: 구간 4개 x 20 시점 x 뼈 11개의 방향 (기준 동작과 같은 좌표·시점). 뼈 길이는 넣지 않는다.
2. 모델: 양방향 LSTM 인코더 -> 잠재 벡터(16) -> 양방향 LSTM 디코더. 프로 스윙 796개로 학습 (β = 1.0).
   스트라이드가 안 찍힌 영상도 다루도록 학습 때 스트라이드를 일부러 가린다.
3. 사용자 스윙을 넣었다 꺼내면 VAE 가 다시 만든 스윙이 나온다. 스윙 전체를 한꺼번에 다시 만들기 때문에,
   한 관절이 바뀌면 함께 움직이는 관절도 같이 맞춰진다.
4. **적용 기준.** VAE 는 처음 보는 사람의 스타일을 다 재현하지 못해 실수 없는 스윙도 평균 12도쯤 바꾼다.
   그래서 실수 없는 프로 스윙에서 VAE 가 시점·뼈마다 보통 바꾸는 각도(`floor_deg`, 중앙값)를 모델에 저장해 두고,
   그 시점에서 가장 크게 바뀌는 뼈 2개가 보통의 **2.5배**를 넘기 시작하면 섞기 시작해 **3.5배**에서 VAE 자세를
   그대로 쓴다. 앞뒤 2 시점까지 넓히고 매끄럽게 이어서 갑자기 바뀌지 않게 한다. 나머지 순간은 사용자 자세 그대로다.
   적용하는 순간에는 몸 전체에 VAE 자세를 쓴다 (`applied`, 시점별 0~1).
5. 사용자 자신의 뼈 길이(중앙값)로 다시 조립한다.

## 검증 (2026-11-12, 학습에 쓰지 않은 선수 26명, 스윙 105개)

정답이 없어서 두 가지로 간접 검증했다.

**스타일 보존** 실수 없는 프로 스윙을 넣었을 때 바뀌는 정도 (뼈 평균 각도)

| 적용 기준 2.5배 | 기준 없이 VAE 그대로 | 모두에게 같은 대표 자세 |
|---|---|---|
| 6.6도 (시점의 42% 에 적용) | 12.3도 | 16.1도 |

**실수 복원** 프로 스윙에 실수를 일부러 넣고 원래 스윙으로 얼마나 돌아오는지 (도, 낮을수록 좋음)

| 넣은 실수 | 넣은 크기 | 적용 기준 2.5배 | 기준 없이 | 단순 계산* |
|---|---|---|---|---|
| 앞 무릎 과하게 굽힘 (착지~스윙) | 23.2 | 9.8 | 9.1 | 14.7 |
| 상체 앞으로 쏠림 (스윙) | 18.8 | 7.5 | 6.5 | 9.9 |
| 뒷팔꿈치 들림 (스트라이드 후반~착지 후) | 26.6 | 21.2 | 16.8 | 19.6 |
| 어깨 일찍 열림 (착지 후) | 29.0 | 12.2 | 10.0 | 19.6 |

\* 단순 계산: 대표 자세에서 프로 퍼짐의 1.5배보다 멀리 간 뼈만 그 경계까지 당김.

- 무릎, 상체, 어깨 실수는 대부분 되돌린다. 실수를 넣지 않은 뼈가 덩달아 바뀌는 정도는 2~3도.
- **뒷팔꿈치 들림은 잘 못 고친다.** 프로 사이에서도 뒷팔 높이가 많이 달라 VAE 가 실수로 보지 않는다.
- 적용 기준을 높이면 실수 없는 스윙은 덜 바뀌지만 실수도 놓친다.

  | 기준 | 실수 없는 스윙 | 앞 무릎 | 상체 | 어깨 | 뒷팔꿈치 |
  |---|---|---|---|---|---|
  | 2배 | 9.1 | 9.2 | 6.6 | 10.4 | 18.8 |
  | **2.5배** | **6.6** | **9.8** | **7.5** | **12.2** | **21.2** |
  | 3배 | 4.5 | 12.0 | 10.0 | 16.0 | 23.8 |

- 잠재 차원을 32/64, 은닉 128 로 키워도 실수 없는 스윙이 바뀌는 정도(11~12도)는 줄지 않았다.
  관절 좌표 흔들림 몫은 0.4도뿐이라, 처음 보는 선수의 스타일을 다 재현하지 못하는 데이터 양의 한계로 보인다.

## 알아둘 점

- 프로 영상만으로 학습했다. 아마추어 스윙에서 어떻게 동작하는지는 사용자 영상으로 다시 확인해야 한다.
- 프로 스윙에도 시점의 약 40% 에서 적용이 켜진다 (2.5배 기준이 실수 없는 스윙에서도 꽤 자주 넘는다).
  화면에서는 `applied` 가 큰 순간이나 `largest_changes` 위주로 보여주는 것이 좋다.
- 점수 반영은 검증 후 따로 논의한다 (VAE 거리 점수를 기존 점수와 나란히 기록만 해 보는 방식 등).

## 다시 학습하기

```
python scripts/train_pose_vae.py --final      # 검증 출력 후, 검증 선수까지 포함해 다시 학습하고 저장
python scripts/train_pose_vae.py --no-save    # 검증만
```

기준 모델과 같은 스윙·이벤트를 쓰므로 `build_reference_model.py` 를 다시 돌렸으면 이것도 다시 학습한다. CPU 로 약 20분.
